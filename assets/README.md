`PageMateDemoSans.ttf` is a static, renamed subset of Noto Sans SC (weight 400), used only to generate the bundled example PDF. The glyph set covers the example content in `server/demo.ts`.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

License: SIL Open Font License 1.1, reproduced in `FONT-LICENSE.txt`.

The variable font was instantiated and subset using fontTools 4.67.0. Modified family name: PageMate Demo Sans. PDF embedding uses the full pre-subset file because runtime CJK subsetting in pdf-lib/fontkit produced invalid glyph mappings in our rendering checks.
